# Reglas Globales del Agente

Estas reglas son de **cumplimiento obligatorio** para todos los agentes y asistentes operando en este proyecto.

## 1. Lectura Obligatoria de Skills

Antes de iniciar cualquier tarea, proponer soluciones, revisar código o escribir una sola línea de código, **estás OBLIGADO a**:

1. Revisar la carpeta `.agent/skills/` y leer detenidamente el propósito de cada skill disponible.
2. Si la tarea encomendada se relaciona con una skill existente (por ejemplo, registrar un aprendizaje, o crear una nueva skill), **debes** leer el archivo `SKILL.md` correspondiente utilizando tus herramientas de lectura de archivos.
3. Aplicar estrictamente todas las reglas, plantillas y directivas de acción estipuladas en las skills.

El incumplimiento de esta regla va en contra de las directrices principales de este proyecto. No asumas que conoces el contenido de las skills por tus conocimientos pre-entrenados; **siempre lee la fuente de verdad en `.agent/skills/`**.
