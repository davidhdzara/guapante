# Índice de Base de Conocimiento (Aprendizajes)

Este documento centraliza y organiza todas las lecciones aprendidas, resoluciones de bugs complejos y convenciones técnicas descubiertas durante el desarrollo e implementación del proyecto Guapante.

## 📊 Contabilidad y Finanzas

- [Configuración Anglosajona de Categorías B2B](./aprendizajes/contabilidad/parametrizacion-anglosajona-categorias.md): Por qué usar el método "Automatizado", mapeo exacto de cuentas transitorias y de inventario, y beneficios operativos de evitar cuentas globales.
- [Catálogo de Gastos y Servicios Operativos](./aprendizajes/contabilidad/catalogo-gastos-servicios.md): Parámetros base para mapear facturas de operaciones B2B usando productos tipo "Servicio" hacia cuentas de los Grupos 51 y 52 (Odoo B2B Agro).
- [Ubicación de Archivos Maestros](./aprendizajes/contabilidad/rutas-archivos-maestros.md): Mapa estático de las rutas locales y archivos base para la parametrización en Odoo 18.
- [Antipatrón: Eliminar Diarios Nativos](./aprendizajes/contabilidad/antipatron-eliminar-diarios-nativos.md): Por qué no se deben borrar los diarios predeterminados de Odoo, riesgos de bajo nivel, y cómo implementar la "Estrategia de Reciclaje".
