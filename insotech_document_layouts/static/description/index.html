InSoTech Premium Document Layouts

Transform your Odoo reports into professional B2B documents

A premium document layout that brings modern typography, brand-aligned colors, and a clean visual hierarchy to your quotations, invoices, and all PDF reports.

Key Features

🎨 Modern Typography

Montserrat for headings, Open Sans for body text, JetBrains Mono for financial data. All fonts bundled locally.

🔵 Brand Colors

Automatically inherits your company primary and secondary colors. No hardcoded values.

📄 PDF-Safe Design

100% wkhtmltopdf-safe. No flexbox, no CSS3 gradients. Guaranteed rendering in every PDF.

How to Activate

  1. Install the module
  2. Go to Settings → Configure Document Layout
  3. Select "InSoTech" from the layout selector
  4. Your company colors are applied automatically

Compatibility

✅ Odoo V19 Community & Enterprise
✅ Quotations, Invoices, Purchase Orders, Delivery Slips
✅ sale_subscription, sale_management, account, purchase, stock
✅ All languages supported
