Trial Balance by Partner

Advanced Colombian accounting report for Odoo 18. View account balances grouped by partner with NIT, document type, and fiscal year-aware initial balances.

🇨🇴 Colombian Localization 📊 account_reports Framework 🔒 Multi-company

Overview

The Trial Balance by Partner report is an essential tool for Colombian accountants. It provides a hierarchical view of account balances grouped by partner (third party), displaying the partner's tax ID (NIT), document type, business name, and calculated balances that respect the Colombian fiscal year rules.

Built on Odoo's native account_reports framework, this module integrates seamlessly with all standard filters (date range, journals, analytic accounts, partners) and supports Excel/PDF export out of the box.

Key Features

📋

Account → Partner Hierarchy

Foldable account lines that expand to show each partner's individual balances within that account.

🆔

Colombian NIT Formatting

Automatic NIT formatting with verification digit (e.g., 900.123.456-7). Supports CC, CE, and other ID types.

📅

Fiscal Year-Aware Balances

Initial balances correctly handle Balance Sheet vs. P&L accounts per Colombian fiscal year rules.

🔍

Advanced Filters

Filter by date range, journals, partners, analytic accounts. Search bar and hide-zero-lines toggle included.

⚡

Optimized Performance

Lazy loading: partner data is fetched only when expanding an account. Batch loading for "Unfold All" mode.

📤

Excel & PDF Export

Native export to XLSX and PDF via the standard Odoo report framework. No extra configuration needed.

Report Columns

Column Description Type
Tipo Doc. Partner identification type (NIT, Cédula de Ciudadanía, CE, etc.) String
NIT / Identificación Tax ID formatted per Colombian standards (e.g., 900.123.456-7) String
Razón Social Partner's legal name / business name String
Saldo Anterior Opening balance (fiscal year-aware for BS vs. P&L accounts) Monetary
Débito Total debits in the selected period Monetary
Crédito Total credits in the selected period Monetary
Saldo Final Ending balance = Initial + Debit - Credit Monetary

How to Use

  1. Install the module from the Apps menu. Search for "Balance por Terceros" or "CO Trial Balance".
  2. Navigate to the report: Accounting → Reports → Audit Reports → Balance por Terceros
  3. Select your filters: date range, journals, partners, or analytic accounts.
  4. Click on any account line to expand and see the detailed partner breakdown.
  5. Export to Excel (XLSX) or PDF using the buttons at the top of the report.
